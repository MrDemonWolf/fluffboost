FluffBoost is free, and stays free. Premium is a small optional upgrade for
servers that want control over exactly when the quote arrives.

## What premium adds

The one thing: **custom scheduling**. See [Scheduling](/docs/scheduling) for the
full command.

- Daily, weekly, or monthly delivery
- A custom time (`HH:mm`)
- Any IANA timezone
- A specific day for weekly / monthly

Everything else — the daily quote, community suggestions, admin tools, rotating
status — is free for every server, forever.

## How billing works

Premium uses **Discord's built-in App Subscriptions**, so it's handled entirely
by Discord — no separate account, no card details shared with the bot.

<Steps>

<Step>

### Open the upsell

Run `/premium`. If the server isn't subscribed, you'll see the premium info with
a purchase button.

</Step>

<Step>

### Subscribe through Discord

Use the button to subscribe via Discord's own checkout.

</Step>

<Step>

### Customize your schedule

Run `/premium` again to confirm it's active, then set your schedule with
`/setup schedule`.

</Step>

</Steps>

<Callout type="info">
  Premium is per-server. If it lapses, your custom schedule is saved and simply
  pauses until you re-subscribe — see
  [If premium lapses](/docs/scheduling#if-premium-lapses).
</Callout>
