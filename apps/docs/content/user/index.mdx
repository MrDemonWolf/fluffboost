FluffBoost delivers one uplifting, furry-friendly motivational quote to your
Discord server every day — on your schedule, in your timezone, partly written
by your own community.

This guide is for **server owners and members**. If you want to run or contribute
to the bot yourself, head to the [Developers](/developers) docs instead.

## Add FluffBoost in under a minute

<Steps>

<Step>

### Invite the bot

Open the [invite link](https://discord.com/api/oauth2/authorize?client_id=1152416549261561856&permissions=2147551232&scope=bot)
and choose your server. You'll need **Manage Server** permission on that server.

</Step>

<Step>

### Choose a channel

Run `/setup channel` and pick where the daily quote should land — for example
`#daily-motivation`.

</Step>

<Step>

### That's it

A quote arrives on the default schedule (8:00 AM, America/Chicago). Want a
different time? See [Scheduling](/docs/scheduling).

</Step>

</Steps>
