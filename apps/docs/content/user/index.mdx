FluffBoost delivers uplifting, furry-friendly motivational quotes to your
Discord server. Start with the free daily 8:00 AM America/Chicago schedule, or
use Premium to choose a different frequency, time, and timezone.

This guide is for **server owners and members**. If you want to run or contribute
to the bot yourself, head to the [Developers](/developers) docs instead.

## Add FluffBoost to your server

<Steps>

<Step>

### Invite the bot

Open the <a href={site.inviteUrl}>invite link</a>
and choose your server. Discord requires **Manage Server** to add an app;
FluffBoost's setup commands require **Administrator**.

</Step>

<Step>

### Choose a channel

Run `/setup channel` and pick where the daily quote should land — for example
`#daily-motivation`.

</Step>

<Step>

### That's it

A quote arrives on the default schedule (8:00 AM, America/Chicago). Want a
different time? See [Scheduling](/docs/scheduling).

</Step>

</Steps>
