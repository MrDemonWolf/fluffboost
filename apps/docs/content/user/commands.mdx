FluffBoost uses Discord slash commands. Type `/` in your server to see them with
inline help.

## General

Anyone can use these.

| Command       | Description                           |
| ------------- | ------------------------------------- |
| `/about`      | Learn about the bot and its creators  |
| `/help`       | View available commands               |
| `/invite`     | Get the bot invite link               |
| `/quote`      | Receive an instant motivational quote |
| `/suggestion` | Suggest a quote for review            |
| `/premium`    | View premium subscription info        |
| `/changelog`  | View recent changes                   |

`/suggestion` and `/premium` work only inside a server.

## Setup

Requires **Administrator** in the server.

| Command           | Description                              |
| ----------------- | ---------------------------------------- |
| `/setup channel`  | Set the quote delivery channel           |
| `/setup schedule` | Customize delivery frequency and time (premium) |

## Admin

These commands manage the bot's **shared** quotes, activities, and suggestion
queue. They are restricted to users the bot operator authorizes in `ALLOWED_USERS`;
being an administrator of your own server does not grant access.

Discord also shows `/admin` only to members with **Administrator** by default.
An authorized operator who is not an administrator of the server they are in
will not see it there unless a server admin adds a command override under
**Server Settings → Integrations**.

| Command                     | Description                   |
| --------------------------- | ----------------------------- |
| `/admin quote create`       | Add a new motivational quote  |
| `/admin quote list`         | List all quotes               |
| `/admin quote remove`       | Remove a quote                |
| `/admin activity create`    | Add a bot status activity     |
| `/admin activity list`      | List all activities           |
| `/admin activity remove`    | Remove an activity            |
| `/admin suggestion approve` | Approve a suggested quote     |
| `/admin suggestion reject`  | Reject a suggested quote      |
| `/admin suggestion list`    | List suggestions              |
| `/admin suggestion stats`   | View suggestion statistics    |

<Callout type="info">
  Owner-only commands (test entitlements for premium) live in the
  [Developers](/developers) docs, since they're for whoever runs the bot.
</Callout>
